# Code of conduct

## Our standard

Project spaces should be safe and useful for everyone. Be respectful, discuss
the work rather than the person, welcome differing levels of experience, and
avoid harassment, threats, sexualized attention, discrimination, doxxing, or
publishing another person's private information.

## Scope

This applies in repository issues, pull requests, reviews, discussions, and
other spaces where someone is representing the project.

## Enforcement

Report conduct concerns to the repository maintainers through GitHub's private
reporting tools where available. Do not post sensitive evidence publicly. If no
private channel is configured, open a detail-free issue requesting one.

Maintainers may edit or remove contributions, lock discussions, issue warnings,
or temporarily or permanently restrict participation. They should consider
context, impact, repeated behavior, and the safety of the people involved, and
should handle reports as confidentially as practical.

Before public release, the maintainer must add a verified private conduct
contact; this document does not invent an unverified address.
